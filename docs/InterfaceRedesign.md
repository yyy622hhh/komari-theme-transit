# Transit 界面改造（M4）

本轮落实已确认的「网络总览」和「简化拓扑」设计，按 M4 展示调整及 M6 测试组织，不修改探测目标、回程规则、伴生协议或 `transit-route:` 标签。

## 网络总览

- 三网质量前置，联通／电信／移动各占一列；回程识别按同一顺序对齐。
- 部分运营商没有回程记录时保留其列位，不将其他运营商的结果向左补位。
- 大数字仍为近 1 小时平均时延，失败率和当前状态独立展示。TCP 失败率不代表业务流量丢包。
- 保留原始样本交互、采样详情、旧／未知回程提示和依据浮层；无回程数据不生成假结果。
- CPU、内存、硬盘、上下行、流量额度、价格与到期信息位于下方。完整容量和 Load 可在节点详情查看。
- 使用不透明卡片底色保证文字对比度；个人壁纸仍可设置，但不透入数据卡片。普通卡片模式保持原布局。
- 保留管理员运维、维护／静默／离线状态、异常原因和自定义洞察面板。默认密度仍是 compact。

## 简化拓扑

- 每条线路一行，节点与连接信息并列；手机和平板改为纵向排列。
- 默认只展示当前探测状态、历史采样、平均时延及协议。历史评分、基线、排名、事件和诊断报告保留在线路详情。
- 箭头标记已匹配来源的探测方向：入口段由线路机探测运营商目标，后续段正向。静态基线或来源不匹配时不绘制方向箭头。
- 导航在同一公开首页内定位「总览／拓扑」，共享原有请求和采样状态；不新增页面级 API 或每卡轮询。
- 导航高亮共享帧节流的滚动／窗口监听；尊重减少动态效果设置，退出首页时释放订阅。
- 尚未配置线路时，访客的拓扑导航进入只读空状态；添加及管理操作仍仅对管理员显示。

## 验收

重点覆盖 320／390／768／1440 像素、长名称、五位时延、三网列对齐、当前恢复但历史失败、缺样本／离线／静态基线、管理员和访客权限、详情返回及动画开关。

本次视觉变化需要审阅新版截图；不可通过放宽像素阈值或批量更新本地／权威基线掩盖回归。截图使用测试数据，不表示真实线上线路状态。

本地验证（2026-08-31）：1353 项单测、74 项跨浏览器功能测试、2 项性能测试通过；lint、类型、源码体积、图标、生产构建、包结构、首屏体积、可重复构建及依赖审计通过。新增覆盖页面底部的导航高亮、部分回程列位、访客空状态以及动画开关下的首页往返。

v1.4.2 的插件和助手仅同步版本元数据，协议和执行逻辑不变；已有助手不需要批量升级。部署前备份旧主题、插件和长期存储；重启后核验状态文件继续保存且旧助手记录保留，不通过迁移真实监测任务来验收。

本地视觉套件 154 项通过（含 9 项无障碍），6 处像素基线因改版不同（总览深色／浅色／移动端、排序工具栏、服务器列表、壁纸管理预览）。已逐项检查实际截图，未放宽断言或覆盖本地基线；权威基线须通过 Visual Baseline 工作流生成、审查后提交。
